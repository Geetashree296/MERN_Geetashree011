# MERN-GEETASHREE-011

## Project Title

MERN Stack Web Application

## Description

This project is a web application developed using the MERN stack. It contains a separate frontend and backend structure.

The frontend is developed using React.js and Vite, while the backend contains the server-side part of the application.

The project demonstrates the implementation of a modern web application with reusable React components and a separate backend.

## How to Run the Project

### Frontend

Open the frontend directory:

```bash
cd frontend
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### Backend

Open a separate terminal and navigate to the backend directory:

```bash
cd Backend
```

Install the backend dependencies:

```bash
npm install
```

Start the backend server using the appropriate command configured in the backend `package.json`.
